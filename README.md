# Игра «Ping-Pong» между процессами

В этом репозитории представлены две реализации простой игры "ping-pong" с использованием механизмов межпроцессного взаимодействия (**IPC**) для **N процессов** (от 2 до 5).

Каждый процесс по кольцу передаёт число следующему. Получатель увеличивает значение на 1 и передаёт дальше. Игра завершается, когда число превышает заданный максимум.

## Описание

Главный процесс создаёт `N-1` дочерних процессов и начинает передачу значения по кольцу. Каждый процесс выводит текущее значение и свой PID при получении данных.

Реализованы два варианта:

1. `pingpong_pipes.c` — Обмен данными через **отдельные каналы (pipe)** между каждой парой процессов.
2. `pingpong_signal.c` — Обмен через **один общий канал**, синхронизация доступа осуществляется с помощью **сигналов**.

## Сборка

Скомпилировать программы можно с помощью `gcc`:

```bash
gcc -o pingpong_pipes pingpong_pipes.c
gcc -o pingpong_signal pingpong_signal.c
```
## Запуск
Обе программы принимают **три аргумента командной строки**:
```bash
./имя_программы N начальное_значение конечное_значение
```
- N — число процессов
- начальное_значение — с какого числа начинается игра
- конечное_значение — при каком числе игра завершается
### Примеры запуска:
```bash
./pingpong_pipes 3 1 10
./pingpong_signal 4 2 15
```
## Файлы
- pingpong_pipes.c — Вариант с использованием **отдельных pipe** для каждой пары процессов.
- pingpong_signal.c — Вариант с использованием **одного pipe** и **сигналов** для управления доступом.
## Подробности
### 1. pingpong_pipes.c:
- Каждый процесс связан с соседом направленным каналом.
- Последний процесс соединяется с первым — получается кольцо.
- Завершение происходит, как только значение превысит максимум.

### 2. pingpong_signal.c:
- Все процессы используют один общий канал.
- Для управления доступом к чтению/записи используется механизм сигналов (SIGUSR1 и т.п.).
- Обеспечивается корректная синхронизация и порядок передачи.
## Пример вывода
```bash
curr N: 1, pID: 12345
curr N: 2, pID: 12346
curr N: 3, pID: 12347
curr N: 4, pID: 12348
...
```
Каждая строка показывает текущее значение и PID процесса, который его обрабатывает.
